Елементи інтерфейсу користувача

Призначення кожного елемента та живі приклади.

1Radiobutton

Дозволяє обрати лише один варіант із набору.

  • Використовується для взаємовиключних виборів (наприклад, стать).
  • Кнопки в групі об'єднані спільним атрибутом name.

4Tabs

Організовують контент у окремі вкладки, які перемикаються кліком по заголовку.

  • Використовуються для навігації між пов'язаними розділами (профіль/налаштування).
  • Зменшують захаращеність інтерфейсу.

5Button

Запускає дію після натискання (відправити, зберегти, видалити).

  • Може мати різні стилі за важливістю (основна, другорядна, небезпечна).
  • Використовується для відправки форм, навігації тощо.

6Text label

Надає інформацію або описує інші елементи інтерфейсу.

  • Використовується для назв полів, підказок і повідомлень про стан.
  • Покращує доступність і зрозумілість.

7Link

Переводить користувача на іншу сторінку або ресурс.

  • Зазвичай виділене кольором і підкресленням.
  • Може відкриватися в тій самій або новій вкладці.

  • Використовується для підказок, пояснень і додаткових деталей.
  • Не захаращує інтерфейс.

10Data grid

Відображає табличні дані з сортуванням, фільтрацією та редагуванням. Клікніть на заголовок, щоб відсортувати.

  • Використовується в таблицях, адмін-панелях, звітах.
  • Підтримує пагінацію, пошук і редагування «на місці».
